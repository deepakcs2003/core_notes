🚀 Spring Boot REST API Development

Complete Guide with Examples & Interview Questions

🌱 1. What is a REST API?

REST API (Representational State Transfer) is a way for applications to communicate using HTTP but exchanging data (usually JSON) instead of web pages.

HTTP Method Action Example
GET Read data Get all students
POST Create data Add a new student
PUT Update data Update student info
DELETE Delete data Remove a student

🚀 2. Common Annotations in Spring Boot

✅ @SpringBootApplication

Marks the main class of the Spring Boot application. It combines:

  • @Configuration - defines beans
  • @EnableAutoConfiguration - starts Spring Boot automatically
  • @ComponentScan - scans for components, controllers, etc.
@SpringBootApplication
public class MyApp {
    public static void main(String[] args) {
        SpringApplication.run(MyApp.class, args);
    }
}

✅ @RestController

  • Used on a class to make it a REST API controller
  • Automatically converts return values to JSON
  • Combination of @Controller + @ResponseBody
@RestController
public class HelloController {
    @GetMapping("/hello")
    public String sayHello() {
        return "Hello Spring Boot!";
    }
}

✅ @RequestMapping

Used at class or method level to map URLs to controllers.

@RestController
@RequestMapping("/api/students")
public class StudentController {
    @GetMapping("/welcome")
    public String welcome() {
        return "Welcome to Student API!";
    }
}

✅ HTTP Method Annotations

Annotation HTTP Method Use
@GetMapping GET Retrieve data
@PostMapping POST Create new data
@PutMapping PUT Update existing data
@DeleteMapping DELETE Remove data

🗃️ 3. In-Memory CRUD API Example

Step 1: Create the Model

public class Student {
    private int id;
    private String name;
    private int age;

    public Student(int id, String name, int age) {
        this.id = id;
        this.name = name;
        this.age = age;
    }

    // Getters & Setters
    public int getId() { return id; }
    public String getName() { return name; }
    public int getAge() { return age; }
    public void setId(int id) { this.id = id; }
    public void setName(String name) { this.name = name; }
    public void setAge(int age) { this.age = age; }
}

Step 2: Create the Controller (Complete CRUD)

@RestController
@RequestMapping("/api/students")
public class StudentController {

    private List<Student> students = new ArrayList<>(
        List.of(
            new Student(1, "Deepak", 20),
            new Student(2, "Shreeram", 21)
        )
    );

    // GET: Fetch all students
    @GetMapping
    public List<Student> getAllStudents() {
        return students;
    }

    // GET: Fetch student by ID
    @GetMapping("/{id}")
    public Student getStudentById(@PathVariable int id) {
        return students.stream()
                       .filter(s -> s.getId() == id)
                       .findFirst()
                       .orElseThrow(() -> new RuntimeException("Student not found"));
    }

    // POST: Add new student
    @PostMapping
    public Student addStudent(@RequestBody Student student) {
        students.add(student);
        return student;
    }

    // PUT: Update student
    @PutMapping("/{id}")
    public Student updateStudent(@PathVariable int id, @RequestBody Student updated) {
        for (Student s : students) {
            if (s.getId() == id) {
                s.setName(updated.getName());
                s.setAge(updated.getAge());
                return s;
            }
        }
        throw new RuntimeException("Student not found");
    }

    // DELETE: Remove student
    @DeleteMapping("/{id}")
    public String deleteStudent(@PathVariable int id) {
        students.removeIf(s -> s.getId() == id);
        return "Student removed successfully!";
    }
}

💡 4. Additional Important Concepts

🧭 @PathVariable

Extracts data from URL path

@GetMapping("/students/{id}")
public Student getStudent(@PathVariable int id) { 
    // Extract id from URL
    return studentService.findById(id);
}

📩 @RequestBody

Gets JSON data from the request body

@PostMapping("/students")
public Student createStudent(@RequestBody Student student) {
    // student object is automatically created from JSON
    return studentService.save(student);
}

💬 @ResponseStatus

Sets custom HTTP response status

@PostMapping
@ResponseStatus(HttpStatus.CREATED)
public Student createStudent(@RequestBody Student student) {
    return studentService.save(student);
}

⚠️ Exception Handling

@ControllerAdvice
public class GlobalExceptionHandler {
    
    @ExceptionHandler(RuntimeException.class)
    public ResponseEntity<String> handleException(RuntimeException ex) {
        return new ResponseEntity<>(ex.getMessage(), HttpStatus.NOT_FOUND);
    }
}

🎯 Important Interview Questions

Q1: What is the difference between @Controller and @RestController?

Answer: @RestController is a combination of @Controller and @ResponseBody. @Controller is used for traditional MVC applications that return views, while @RestController is specifically for RESTful web services that return data (usually JSON/XML). With @RestController, you don't need to annotate every method with @ResponseBody.

Q2: What is the difference between @PathVariable and @RequestParam?

Answer:
• @PathVariable: Extracts values from the URI path (e.g., /users/{id})
• @RequestParam: Extracts query parameters from the URL (e.g., /users?id=123)
Example: @GetMapping("/users/{id}") uses @PathVariable, while @GetMapping("/users") with ?name=John uses @RequestParam

Q3: What are the HTTP status codes commonly used in REST APIs?

Answer:
• 200 OK: Successful GET, PUT, or DELETE
• 201 Created: Successful POST request
• 204 No Content: Successful request with no response body
• 400 Bad Request: Invalid request from client
• 404 Not Found: Resource not found
• 500 Internal Server Error: Server-side error

Q4: What is @RequestBody and when do you use it?

Answer: @RequestBody is used to bind the HTTP request body to a domain object. It's commonly used with POST and PUT requests where you're sending data to the server. Spring automatically deserializes the JSON/XML from the request body into a Java object.

Q5: How do you handle exceptions in Spring Boot REST APIs?

Answer: There are several ways:
• @ExceptionHandler: Handle exceptions at controller level
• @ControllerAdvice: Global exception handling across all controllers
• @ResponseStatus: Map exceptions to HTTP status codes
• ResponseEntityExceptionHandler: Extend this class for customized exception handling

Q6: What is the difference between PUT and PATCH methods?

Answer:
• PUT: Updates the entire resource. You send the complete updated object.
• PATCH: Partially updates the resource. You send only the fields that need to be updated.
Example: PUT requires all fields, PATCH allows updating just the name without sending other fields.

Q7: What is @SpringBootApplication annotation and what does it include?

Answer: @SpringBootApplication is a combination of three annotations:
• @Configuration: Tags the class as a source of bean definitions
• @EnableAutoConfiguration: Enables Spring Boot's auto-configuration mechanism
• @ComponentScan: Scans for components in the current package and sub-packages

Q8: How do you validate request data in Spring Boot?

Answer: Use @Valid or @Validated with validation annotations:
• @NotNull, @NotEmpty, @NotBlank
• @Size(min, max)
• @Min, @Max
• @Email, @Pattern
Example: public Student create(@Valid @RequestBody Student student)

Q9: What is the purpose of @ResponseStatus annotation?

Answer: @ResponseStatus is used to set the HTTP status code for a response. It can be applied to exception classes or controller methods to return appropriate status codes like 201 (Created), 204 (No Content), 404 (Not Found), etc., instead of the default 200 (OK).

Q10: What is REST and what are its principles?

Answer: REST (Representational State Transfer) principles include:
• Client-Server: Separation of concerns
• Stateless: Each request contains all necessary information
• Cacheable: Responses can be cached
• Uniform Interface: Standard HTTP methods
• Layered System: Client doesn't know if connected directly to end server
• Code on Demand (optional): Server can send executable code

Q11: How would you implement pagination in a REST API?

Answer: Use @RequestParam to accept page number and size:

@GetMapping("/students")
public Page<Student> getStudents(
    @RequestParam(defaultValue = "0") int page, 
    @RequestParam(defaultValue = "10") int size) {
    Pageable pageable = PageRequest.of(page, size);
    return studentRepository.findAll(pageable);
}
Use Spring Data's Pageable interface and return Page object containing results and pagination metadata.

Q12: What is Content Negotiation in REST APIs?

Answer: Content Negotiation allows the same URI to serve different representations (JSON, XML, etc.) based on the Accept header in the request. Spring Boot supports this through the produces attribute in mapping annotations:

@GetMapping(value = "/student", produces = {"application/json", "application/xml"})
💡 Pro Tip: Always use proper HTTP status codes, implement global exception handling, validate input data, and follow RESTful naming conventions (plural nouns for resources, HTTP methods for actions).
