What is JDBC?

JDBC = Java Database Connectivity

A Java API that enables Java programs to execute SQL statements against any relational database (MySQL, Oracle, PostgreSQL, SQL Server, etc.)

💡 Think of JDBC as a bridge between Java code and the database.

Core JDBC Concepts

Concept Description Interview Tip
Driver Java class that implements java.sql.Driver Know Class.forName() vs auto-loading (Java 6+)
DriverManager Manages drivers & establishes connections DriverManager.getConnection(url, user, pwd)
Connection Represents a session with the DB Always close in finally or try-with-resources
Statement Executes static SQL Vulnerable to SQL injection

JDBC Architecture

Type-4 Driver (Thin driver) → Direct TCP/IP → Recommended for MySQL

The JDBC Architecture acts as a bridge between a Java application and a database. It allows Java programs to execute SQL statements, retrieve results, and perform database operations in a standardized way.

🧩 Components of JDBC Architecture

  • 1. JDBC API: Provides classes and interfaces (like Connection, Statement, ResultSet) that allow Java applications to interact with databases in a consistent manner.
  • 2. JDBC Driver Manager: Manages different types of database drivers. It loads the driver classes dynamically and establishes a connection using the appropriate driver.
  • 3. JDBC Drivers: These are implementations provided by database vendors to connect Java applications to specific databases. There are 4 types of drivers (Type 1 to Type 4), and for MySQL, we commonly use the Type 4 (Thin Driver).
  • 4. Database: The backend system (like MySQL, Oracle, or PostgreSQL) that stores the actual data and executes SQL queries sent from the Java application.

⚙️ Flow of JDBC Architecture

  1. The Java application uses the DriverManager class to load and register the JDBC driver.
  2. A connection is established between the Java program and the database using getConnection().
  3. SQL statements are created and executed using Statement or PreparedStatement.
  4. The database processes the SQL query and sends the results back to the application via ResultSet.
  5. Finally, all resources like connections and statements are closed to free up memory.
Example: When connecting to MySQL, we typically use the driver class com.mysql.cj.jdbc.Driver and the Type-4 JDBC driver establishes a direct connection using TCP/IP — making it faster and platform-independent.

Step 4: Useful JDBC Methods & Functions

  • Connection conn = DriverManager.getConnection(url, user, password); → Establish connection.
  • Statement stmt = conn.createStatement(); → Used to execute SQL queries.
  • ResultSet rs = stmt.executeQuery("SELECT * FROM student"); → Retrieves result from database.
  • rs.next() → Moves the cursor to the next row of the result set.
  • rs.getInt("id") → Retrieves integer value from the “id” column.
  • rs.getString("name") → Retrieves string value from the “name” column.
  • rs.getInt("age") → Retrieves the student’s age as an integer.
  • rs.getString("grade") → Retrieves grade value.
  • stmt.executeUpdate("INSERT/UPDATE/DELETE query") → Used for data modification queries.
  • conn.close(), stmt.close(), rs.close() → Closes all database resources.

Step 5: Example Program

Main.java
import java.sql.*;

public class JDBCDemo {
    public static void main(String[] args) {
        try {
            // Load the MySQL driver
            Class.forName("com.mysql.cj.jdbc.Driver");

            // Establish connection
            Connection conn = DriverManager.getConnection(
                "jdbc:mysql://localhost:3306/school?useSSL=false&serverTimezone=UTC",
                "root", 
                "your_password"
            );

            // Create statement and execute query
            Statement stmt = conn.createStatement();
            ResultSet rs = stmt.executeQuery("SELECT * FROM student");

            // Read data
            while (rs.next()) {
                System.out.println(
                    rs.getInt("id") + " | " +
                    rs.getString("name") + " | " +
                    rs.getInt("age") + " | " +
                    rs.getString("grade")
                );
            }

            // Close resources
            rs.close();
            stmt.close();
            conn.close();

        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

Full Working Example (CRUD + Transaction)

JDBCDemo.java
import java.sql.*;

public class JDBCDemo {
    private static final String URL = "jdbc:mysql://localhost:3306/school?useSSL=false&serverTimezone=UTC";
    private static final String USER = "root";
    private static final String PASS = "your_password";

    public static void main(String[] args) {
        try {
            // 1. Load Driver (Optional in Java 6+)
            // Class.forName("com.mysql.cj.jdbc.Driver");

            // 2. Get Connection
            Connection conn = DriverManager.getConnection(URL, USER, PASS);
            conn.setAutoCommit(false); // Start transaction

            // CRUD Operations
            createStudent(conn, "Charlie", 21, "A");
            readStudents(conn);
            updateStudent(conn, 1, "Alice Updated", 23);
            readStudents(conn);
            deleteStudent(conn, 2);
            readStudents(conn);

            conn.commit(); // Success
            closeConnection(conn);

        } catch (SQLException e) {
            e.printStackTrace();
            try (Connection conn = DriverManager.getConnection(URL, USER, PASS)) {
                conn.rollback();
            } catch (SQLException ex) {
                ex.printStackTrace();
            }
        }
    }

    // CREATE
    static void createStudent(Connection conn, String name, int age, String grade) throws SQLException {
        String sql = "INSERT INTO student (name, age, grade) VALUES (?, ?, ?)";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, name);
            ps.setInt(2, age);
            ps.setString(3, grade);
            int rows = ps.executeUpdate();
            System.out.println("Inserted: " + rows + " row(s)");
        }
    }

    // READ
    static void readStudents(Connection conn) throws SQLException {
        String sql = "SELECT * FROM student";
        try (Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {

            System.out.println("\n--- Students ---");
            while (rs.next()) {
                int id = rs.getInt("id");
                String name = rs.getString("name");
                int age = rs.getInt("age");
                String grade = rs.getString("grade");
                System.out.printf("ID: %d | Name: %s | Age: %d | Grade: %s%n", id, name, age, grade);
            }
        }
    }

    // UPDATE
    static void updateStudent(Connection conn, int id, String newName, int newAge) throws SQLException {
        String sql = "UPDATE student SET name = ?, age = ? WHERE id = ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, newName);
            ps.setInt(2, newAge);
            ps.setInt(3, id);
            int rows = ps.executeUpdate();
            System.out.println("Updated: " + rows + " row(s)");
        }
    }

    // DELETE
    static void deleteStudent(Connection conn, int id) throws SQLException {
        String sql = "DELETE FROM student WHERE id = ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, id);
            int rows = ps.executeUpdate();
            System.out.println("Deleted: " + rows + " row(s)");
        }
    }

    // Close Connection
    static void closeConnection(Connection conn) {
        if (conn != null) {
            try {
                conn.close();
                System.out.println("Connection closed.");
            } catch (SQLException e) {
                e.printStackTrace();
            }
        }
    }
}

Best Practices

Practice Why
Use PreparedStatement Prevents SQL injection
Try-with-resources Auto-closes Connection, Statement, ResultSet
Connection Pooling Use HikariCP in production
Batch Processing addBatch(), executeBatch() for bulk inserts
Proper Exception Handling printStackTrace() only in dev; log in prod
Close Resources Avoid leaks
Use ResultSet.TYPE_FORWARD_ONLY Default & fastest

Interview Questions & Answers

Question Answer
Difference between Statement & PreparedStatement? Statement: static SQL, recompiled every time, vulnerable to injection.
PreparedStatement: pre-compiled, uses ?, safe, faster for repeated use.
How to handle transactions in JDBC? conn.setAutoCommit(false); → operations → conn.commit() or conn.rollback()
What is connection pooling? Reusing DB connections instead of creating new ones. Improves performance. Use HikariCP.
Types of JDBC Drivers? 1. Type-1 (JDBC-ODBC)
2. Type-2 (Native)
3. Type-3 (Network)
4. Type-4 (Thin) → Best for MySQL
What is ResultSet concurrency? CONCUR_READ_ONLY (default), CONCUR_UPDATABLE (for updateRow())
How to call stored procedure? Use CallableStatement: call proc_name(?, ?)

Bonus: Stored Procedure Example

Creating Stored Procedure

SQL
DELIMITER //
CREATE PROCEDURE get_student_count(OUT count INT)
BEGIN
    SELECT COUNT(*) INTO count FROM student;
END //
DELIMITER ;

Calling from Java

CallStoredProcedure.java
try (CallableStatement cs = conn.prepareCall("{call get_student_count(?)}")) {
    cs.registerOutParameter(1, Types.INTEGER);
    cs.execute();
    System.out.println("Total students: " + cs.getInt(1));
}
