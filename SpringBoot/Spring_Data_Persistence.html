🌱 Spring Boot Data Persistence

Complete Guide to Database Integration

💡 What Is Data Persistence?

Persistence means saving data permanently — not just in memory (RAM) but in a database, like MySQL or PostgreSQL, so that it remains available even after restarting your app.

In Spring Boot, we handle this using:
  • Spring Data JPA (Java Persistence API)
  • A Database (like H2, MySQL, PostgreSQL)
  • Entity Classes to map Java objects to DB tables

🧩 1. Basic SQL Concepts

Before using JPA, you must understand SQL basics:

Operation SQL Command Description
Create Table CREATE TABLE product (id INT PRIMARY KEY, name VARCHAR(50), price DOUBLE); Creates a new table
Insert Data INSERT INTO product VALUES (1, 'Pen', 10.5); Adds new data
Select Data SELECT * FROM product; Reads data
Update Data UPDATE product SET price = 20 WHERE id = 1; Modifies existing data
Delete Data DELETE FROM product WHERE id = 1; Removes data

These operations are what JPA helps us perform using Java methods instead of SQL.

⚙️ 2. Spring Data JPA Overview

Spring Data JPA is a module that simplifies working with databases. You don't write SQL queries — instead, you work with Java objects.

🧠 Key Benefits:

  • Less boilerplate code
  • Easy CRUD operations
  • Works with any database (MySQL, PostgreSQL, H2, etc.)
  • Uses JpaRepository for DB operations

🧱 3. Important JPA Annotations

Annotation Purpose / Properties Example
@Entity Marks a class as a table in the database. 
@Entity
public class Product { ... }
@Id Marks a field as the primary key of the table. 
@Id
private Long id;
@GeneratedValue Auto-generates the primary key value.
  • IDENTITY → Database auto-increment
  • AUTO → Hibernate chooses based on DB
  • SEQUENCE → Uses database sequence
  • TABLE → Uses a separate table for IDs
 
@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)
private Long id;
@Table(name="table_name") Customizes the table name in the database (optional). 
@Entity
@Table(name = "products")
public class Product { ... }
@Column Customizes a field mapping to a column. Common properties:
  • name → Custom column name
  • nullable → Whether column accepts NULL (default true)
  • unique → Column values must be unique
  • length → Max length for String fields
  • precision → Total digits for decimal numbers
  • scale → Digits after decimal
  • columnDefinition → Custom SQL definition
  • insertable → Include in INSERT (default true)
  • updatable → Include in UPDATE (default true)
 
@Column(
    name = "product_name",
    nullable = false,
    unique = true,
    length = 100
)
private String name;

@Column(
    name = "price",
    nullable = false,
    precision = 10,
    scale = 2,
    columnDefinition = "DECIMAL(10,2)"
)
private Double price;

💾 4. Example: Product Entity

package com.example.demo.model;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;

@Entity
public class Product {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY) // auto increment
    private Long id;
    private String name;
    private double price;

    // Constructors
    public Product() {}
    public Product(String name, double price) {
        this.name = name;
        this.price = price;
    }

    // Getters & Setters
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public double getPrice() { return price; }
    public void setPrice(double price) { this.price = price; }
}
🧠 Understanding:
  • Product = table
  • Each field = column
  • @GeneratedValue auto-generates IDs like 1, 2, 3...

🗂️ 5. Repository Layer

Spring Boot provides JpaRepository to handle CRUD operations easily.

package com.example.demo.repository;

import com.example.demo.model.Product;
import org.springframework.data.jpa.repository.JpaRepository;

// <Entity, PrimaryKeyType>
public interface ProductRepository extends JpaRepository<Product, Long> {
}
Now you get all these methods for free:
  • save(product) → insert or update
  • findAll() → select all
  • findById(id) → select by id
  • deleteById(id) → delete

🧠 6. Service Layer (Business Logic)

This layer holds the logic between controller and repository.

package com.example.demo.service;

import com.example.demo.model.Product;
import com.example.demo.repository.ProductRepository;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import java.util.List;

@Service
public class ProductService {

    @Autowired
    private ProductRepository repo;

    public List<Product> getAllProducts() {
        return repo.findAll();
    }

    public Product addProduct(Product p) {
        return repo.save(p);
    }

    public Product getProductById(Long id) {
        return repo.findById(id).orElse(null);
    }

    public void deleteProduct(Long id) {
        repo.deleteById(id);
    }
}

🌐 7. Controller Layer

package com.example.demo.controller;

import com.example.demo.model.Product;
import com.example.demo.service.ProductService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import java.util.List;

@RestController
@RequestMapping("/products")
public class ProductController {

    @Autowired
    private ProductService service;

    @GetMapping
    public List<Product> getAll() {
        return service.getAllProducts();
    }

    @PostMapping
    public Product add(@RequestBody Product product) {
        return service.addProduct(product);
    }

    @GetMapping("/{id}")
    public Product getById(@PathVariable Long id) {
        return service.getProductById(id);
    }

    @DeleteMapping("/{id}")
    public String delete(@PathVariable Long id) {
        service.deleteProduct(id);
        return "Product deleted!";
    }
}

⚙️ 13. What Is JDBC?

JDBC (Java Database Connectivity) is a standard Java API that lets Java applications connect to relational databases (like MySQL, PostgreSQL, Oracle, etc.) and execute SQL queries.

🔗 JDBC works as a bridge:
Java Application → JDBC API → JDBC Driver → Database

Basic JDBC Example (Pure Java)

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;

public class JdbcExample {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/productdb";
        String username = "root";
        String password = "yourpassword";

        try {
            // Establish connection
            Connection con = DriverManager.getConnection(url, username, password);
            System.out.println("✅ Connected to Database!");

            // Create SQL statement
            String query = "SELECT * FROM product";
            PreparedStatement ps = con.prepareStatement(query);

            // Execute query
            ResultSet rs = ps.executeQuery();

            // Process results
            while (rs.next()) {
                System.out.println(rs.getInt("id") + " - " + 
                                 rs.getString("name") + " - " + 
                                 rs.getDouble("price"));
            }

            con.close();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

🧩 14. JDBC in Spring Boot (JdbcTemplate)

Spring Boot provides JdbcTemplate, which is a simplified wrapper around standard JDBC. You don't need to manually handle connections, exceptions, or closing statements.

Dependencies for JdbcTemplate

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-jdbc</artifactId>
</dependency>

<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
</dependency>

Repository using JdbcTemplate

package com.example.demo.repository;

import com.example.demo.model.Product;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.jdbc.core.BeanPropertyRowMapper;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Repository;
import java.util.List;

@Repository
public class ProductJdbcRepository {

    @Autowired
    private JdbcTemplate jdbcTemplate;

    // Insert
    public int addProduct(Product product) {
        String sql = "INSERT INTO product (name, price) VALUES (?, ?)";
        return jdbcTemplate.update(sql, product.getName(), product.getPrice());
    }

    // Read all
    public List<Product> getAllProducts() {
        String sql = "SELECT * FROM product";
        return jdbcTemplate.query(sql, new BeanPropertyRowMapper<>(Product.class));
    }

    // Read one
    public Product getProductById(Long id) {
        String sql = "SELECT * FROM product WHERE id = ?";
        return jdbcTemplate.queryForObject(sql, new BeanPropertyRowMapper<>(Product.class), id);
    }

    // Update
    public int updateProduct(Product product) {
        String sql = "UPDATE product SET name = ?, price = ? WHERE id = ?";
        return jdbcTemplate.update(sql, product.getName(), product.getPrice(), product.getId());
    }

    // Delete
    public int deleteProduct(Long id) {
        String sql = "DELETE FROM product WHERE id = ?";
        return jdbcTemplate.update(sql, id);
    }
}

🔄 15. JDBC vs JPA Comparison

Feature JDBC (JdbcTemplate) JPA (JpaRepository)
Code Style SQL-based Object-based
You write SQL? ✅ Yes ❌ No
Data mapping Manual (via RowMapper) Automatic (via @Entity)
Speed Slightly faster for small apps Easier for big apps
Recommended for Simple apps, custom SQL queries Enterprise apps, complex relationships
Transaction management Manual (you handle it) Automatic (via JPA)
💡 Real-World Usage: Many Spring Boot apps use both JDBC and JPA:
  • Use JPA for complex entities and relationships
  • Use JdbcTemplate for performance-heavy bulk queries or reports
