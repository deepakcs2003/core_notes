🧠 What is Spring?

Spring is a Java framework that helps you build applications easily. It manages the creation and connection of objects (called beans) automatically.

Spring Framework Architecture

❌ Normal Java

Car car = new Car();
Engine engine = new Engine();
car.setEngine(engine);

✅ Spring Way

@Autowired
Engine engine;

Spring automatically creates and injects the object!

⚙️ What is IoC (Inversion of Control)?

Normally, a class controls how objects are created. But in Spring, the control is inverted — Spring creates objects for you.

IoC Container manages object lifecycle

Without IoC

Car car = new Car(new Engine());

YOU are creating objects

With IoC

@Autowired
Engine engine;

SPRING creates and gives the object

💉 What is Dependency Injection (DI)?

Dependency Injection means giving the required object (dependency) to a class instead of letting it create it.

Example: A car needs an engine. Instead of making its own engine, the engine is injected into the car.

Dependency Injection Concept

@Component
class Engine {
    public String type() {
        return "Diesel Engine";
    }
}

@Component
class Car {
    private final Engine engine;

    @Autowired
    public Car(Engine engine) {   // DI happens here
        this.engine = engine;
    }

    public void start() {
        System.out.println("Car started with " + engine.type());
    }
}

🧩 Types of Dependency Injection

1️⃣ Constructor Injection (✅ Recommended)

Dependency is provided through the constructor.

@Component
class Car {
    private final Engine engine;

    @Autowired
    public Car(Engine engine) {
        this.engine = engine;
    }
}

✅ Advantages: Makes testing easy, makes object immutable

2️⃣ Field Injection

@Component
class Car {
    @Autowired
    private Engine engine;
}

⚠️ Not recommended for large projects — less testable.

3️⃣ Setter Injection

@Component
class Car {
    private Engine engine;

    @Autowired
    public void setEngine(Engine engine) {
        this.engine = engine;
    }
}

🧱 Important Spring Annotations

Annotation Meaning Example
@Component Marks class as a Spring Bean @Component class Engine {}
@Service Used for service layer @Service class PaymentService {}
@Repository Used for database layer @Repository class StudentRepo {}
@Controller Used for web MVC controllers @Controller class HomeController {}
@RestController Returns JSON instead of web pages @RestController class ApiController {}
@Autowired Injects dependency automatically @Autowired Engine engine;
@Primary Choose this bean by default @Primary class DieselEngine {}
@Qualifier Used when multiple beans exist @Qualifier("petrolEngine")
@Scope Creates new bean each time @Scope("prototype")
@Configuration Marks class for bean definitions @Configuration class AppConfig {}
@Bean Defines a bean manually @Bean Engine engine() {...}

🚀 Complete Code Example

Step-by-Step Implementation

📄 Engine.java
package com.example.springdemo;

public interface Engine {
    String getType();
}
📄 DieselEngine.java
package com.example.springdemo;

import org.springframework.stereotype.Component;

@Component
public class DieselEngine implements Engine {
    @Override
    public String getType() {
        return "Diesel Engine";
    }
}
📄 Car.java
package com.example.springdemo;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;

@Component
public class Car {
    private final Engine engine;

    @Autowired
    public Car(Engine engine) {
        this.engine = engine;
    }

    public void start() {
        System.out.println("Car started with " + engine.getType());
    }
}
📄 SpringdemoApplication.java
package com.example.springdemo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.context.ApplicationContext;

@SpringBootApplication
public class SpringdemoApplication {
    public static void main(String[] args) {
        // Start the Spring container
        ApplicationContext context = SpringApplication.run(SpringdemoApplication.class, args);

        // Get the Car bean from container
        Car car = context.getBean(Car.class);

        // Call the method
        car.start();
    }
}
Output:
Car started with Diesel Engine

🔍 How the code works step-by-step:

  1. Spring starts (SpringApplication.run())
  2. It scans for classes with @Component
  3. Finds DieselEngine and Car
  4. Creates an object for both
  5. Sees @Autowired inside Car → injects DieselEngine
  6. You call car.start() → prints engine type

✅ No need for new Car() or new Engine() — Spring handles it all.

🧠 Common Interview Questions & Answers

1️⃣ What is Spring Framework?
Spring is a Java framework used to develop enterprise applications easily. It manages object creation, dependency injection, and provides features for web, data, and security.
2️⃣ What is IoC?
Inversion of Control (IoC) means giving control of object creation to the Spring container instead of the programmer.
3️⃣ What is Dependency Injection (DI)?
Dependency Injection means giving required objects to a class instead of the class creating them itself. It makes code flexible and testable.
4️⃣ Types of Dependency Injection?
• Constructor Injection ✅ (Recommended)
• Field Injection
• Setter Injection
5️⃣ What are Spring Beans?
Beans are objects managed by Spring. Spring creates them, injects dependencies, and manages their lifecycle.
6️⃣ What is ApplicationContext?
It is the Spring container that manages all beans. Used to get beans and start the application.
7️⃣ What is the difference between @Component, @Service, and @Repository?
• @Component: Generic bean
• @Service: Business logic layer
• @Repository: Database layer
8️⃣ What is @Autowired?
It automatically injects dependencies (objects) into a class.
9️⃣ What is @Primary?
If there are multiple beans of the same type, @Primary tells Spring which one to choose by default.
🔟 What is @Qualifier?
Used when there are multiple beans and you want to specify exactly which one to use. Example: @Qualifier("petrolEngine")
1️⃣1️⃣ What is the default bean scope in Spring?
singleton — only one object per application.
1️⃣2️⃣ What is @Scope used for?
To define how many instances of a bean are created.
1️⃣3️⃣ What is the difference between @Controller and @RestController?
• @Controller → returns web page (View)
• @RestController → returns JSON or XML (for REST APIs)
1️⃣4️⃣ Why is constructor injection preferred?
Because it makes the object immutable, and all dependencies are available when the object is created.
1️⃣5️⃣ What happens if two beans have the same type?
Spring throws an error — unless you use @Primary or @Qualifier.
