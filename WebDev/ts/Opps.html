TypeScript Classes
Core Concept

A class is a blueprint (template) for creating objects. The class is the design; objects are the real things created from that design.

Analogy: Class = Car design blueprint  ·  Object = Actual car on the road  ·  color = property  ·  speed() = method
Basic Structure
class Person { name: string; age: number; constructor(name: string, age: number) { this.name = name; this.age = age; } introduce(): string { return `Hi, my name is ${this.name} and I am ${this.age} years old.`; } } const person1 = new Person("Alice", 25); console.log(person1.introduce()); // Hi, my name is Alice and I am 25 years old.
≡
Properties & Methods
Class Members
Properties — Variables inside the class

Store data unique to each object. Each object gets its own copy.

name: string; // text age: number; // number
Methods — Functions inside the class

Operate on the object's own data. Access them with dot notation: obj.methodName().

introduce(): string { return `Hi, I am ${this.name}`; // this = current object }
this keyword

this always refers to the current object. this.name means "the name property of this specific object".

⚡
Constructor
Automatic Initializer

The constructor runs automatically the moment an object is created with new. It receives input values and assigns them to the object.

constructor(name: string, age: number) { this.name = name; // put given name into this object this.age = age; }
Shortcut Constructor

Declare and assign properties in one line using access modifiers in parameters:

constructor(public name: string, public age: number) {} // No need to write this.name = name — it happens automatically
◉
Creating Objects
Instantiation with new

Use the new keyword to create an instance of a class. This calls the constructor automatically.

const p = new Person("Alice", 25); // constructor runs p.introduce(); // call method via dot p.name; // access property via dot
Bank Account Example
class BankAccount { accountHolder: string; balance: number; constructor(holder: string, initial: number) { this.accountHolder = holder; this.balance = initial; } deposit(amount: number): void { this.balance += amount; } getBalance(): string { return `Balance: ${this.balance}`; } } const acc = new BankAccount("John", 500); acc.deposit(200); // balance = 700
⇗
Inheritance
extends keyword

A child class reuses everything from a parent class using extends. Use super() inside the child constructor to call the parent constructor.

class Student extends Person { grade: string; constructor(name: string, age: number, grade: string) { super(name, age); // call parent constructor this.grade = grade; } } const s = new Student("Rahul", 20, "A"); s.introduce(); // ✅ inherited from Person
✓ Inherits name & age
✓ Inherits introduce()
✓ Adds own grade property
Access Modifiers
PUB
public
Accessible Everywhere — Default

If no modifier is written, it is public by default. Public members can be accessed from anywhere — inside the class, child classes, and outside.

class Animal { public name: string; constructor(name: string) { this.name = name; } public makeSound(): void { console.log(`${this.name} makes a sound.`); } } const dog = new Animal('Dog'); console.log(dog.name); // ✅ Dog dog.makeSound(); // ✅ Dog makes a sound.
PRV
private
Only Inside the Class

Private members can only be accessed inside the class where declared. Expose them safely using a public method.

class Person { private ssn: string; constructor(ssn: string) { this.ssn = ssn; } public getSSN(): string { return this.ssn; // ✅ inside class — OK } } const p = new Person('123-45-6789'); console.log(p.getSSN()); // ✅ 123-45-6789
❌  p.ssn — Cannot access private member outside the class
PRT
protected
Inside Class + Child Classes

Protected members work inside the class AND inside child (inherited) classes, but not from outside.

class User { protected age: number; constructor(age: number) { this.age = age; } } class Employee extends User { getRetirementAge(): number { return this.age + 65; // ✅ child class — OK } } const emp = new Employee(30); emp.getRetirementAge(); // ✅ 95
❌  emp.age — Cannot access protected member outside class hierarchy
🔒
readonly
Set Once, Never Change

A readonly property can only be assigned once — at declaration or inside the constructor. After that, it is permanently fixed.

class Car { readonly make: string; readonly model: string; constructor(make: string, model: string) { this.make = make; this.model = model; } } const car = new Car('Toyota', 'Corolla');
❌  car.make = "Honda" — Cannot assign to a readonly property
Interface & ReadonlyArray
interface Point { readonly x: number; readonly y: number; } const p1: Point = { x: 10, y: 20 }; const nums: ReadonlyArray<number> = [1, 2, 3]; // nums.push(4) ❌ nums.pop() ❌ — fully immutable
Real-life: Aadhaar / PAN Card — assigned once, can never be changed. That is readonly.

Abstract Classes
◈
Abstract Classes
Blueprint for Other Classes

An abstract class is a base class that provides rules + shared code to child classes. You cannot create an object of it directly — it must be extended.

❌  new Animal() — Cannot instantiate an abstract class
abstract class Animal { abstract makeSound(): void; // no body — child MUST implement move(): void { // concrete — shared code console.log('Moving...'); } } class Dog extends Animal { makeSound(): void { console.log('Bark'); } } const dog = new Dog(); dog.makeSound(); // Bark dog.move(); // Moving...
✓ Code reuse
✓ Enforces structure
✓ Polymorphism support
✓ Central control
⊘
Abstract Method
No Body — Child Must Implement

An abstract method has no body. It only declares the signature. Every child class must implement it — TypeScript gives a compile error if it doesn't.

abstract class Shape { abstract getArea(): number; // declare only — no code printArea(): void { console.log(`Area: ${this.getArea()}`); // uses abstract method } } class Circle extends Shape { constructor(private radius: number) { super(); } getArea(): number { return Math.PI * this.radius ** 2; } } new Circle(5).printArea(); // Area: 78.53...
⊕
Concrete Method
Shared Implementation in Abstract Class

A concrete (normal) method inside an abstract class has a body. Child classes inherit it and can use it without reimplementing. Abstract classes can also have properties and constructors.

abstract class Person { constructor(public name: string) {} abstract role: string; // abstract property display(): void { // concrete — shared console.log(`${this.name} is a ${this.role}`); } } class Employee extends Person { role = 'Engineer'; constructor(name: string, public empCode: number) { super(name); } } new Employee("James", 100).display(); // James is a Engineer

Interface
Contract / Rule Book

An interface is a rule book. It defines what properties and methods a class must have, but contains no implementation (no code inside). Pure structure only.

Analogy: Interface = Exam rules (must write answers, follow format)  ·  Class = Student (actually writes the answers)
interface Shape { calculateArea(): number; // must exist — no body }
⌘
implements Keyword
Class Agrees to Follow the Interface

A class uses implements to declare it will follow an interface. It must implement every method and property defined, or TypeScript gives a compile error.

interface Shape { calculateArea(): number; } class Rectangle implements Shape { constructor(private w: number, private h: number) {} calculateArea(): number { return this.w * this.h; // ✅ implemented } } console.log(new Rectangle(5, 10).calculateArea()); // 50
❌  Missing any interface method → TypeScript compile error
Payment Example
interface Payment { pay(amount: number): void; } class CreditCard implements Payment { pay(amount: number): void { console.log("Paid via credit card: " + amount); } }
⋈
Multiple Interfaces
implements A, B, C

A class can implement multiple interfaces separated by commas. It must fulfill requirements from all of them. (Unlike extends — you can only extend one class.)

interface Shape { calculateArea(): number; } interface Color { color: string; } class Circle implements Shape, Color { color: string; constructor(private radius: number, color: string) { this.color = color; } calculateArea(): number { return Math.PI * this.radius ** 2; } } const c = new Circle(5, "red"); console.log(c.color); // red console.log(c.calculateArea()); // 78.5...

Getters & Setters
↗
Getter — get
Safe Read Access

A get method lets you read a private value safely. Accessed like a property (no parentheses), but internally it's a function.

class Rectangle { constructor(private _width: number, private _height: number) {} get area(): number { return this._width * this._height; } } const rect = new Rectangle(5, 10); console.log(rect.area); // 50 — accessed like a property, not area()
❌  No setter defined → rect.area = 100 gives an error (read-only)
↙
Setter — set
Safe Write with Validation

A set method lets you update a private value with validation. You can reject invalid data before it reaches the property.

class Employee { private _fullName: string = ''; get fullName(): string { return this._fullName; } set fullName(name: string) { if (name && name.length > 0) { this._fullName = name; } else { console.error('Invalid name.'); } } } const emp = new Employee(); emp.fullName = "John Doe"; // setter called console.log(emp.fullName); // getter called → John Doe emp.fullName = ""; // Invalid name.
✦
Rules & Underscore Convention
Important Constraints
✓ Getter: no parameters, must return a value
✓ Setter: exactly one parameter
✓ Same name for get & set
✓ Used like a property, not a method call
Underscore Convention

Private backing variables use _name (underscore prefix). The public getter/setter uses name without underscore.

private _age: number; // private backing variable get age() { return this._age; } // same name, no underscore set age(v: number) { this._age = v; }
⚙
Real Use Cases
Validation Examples
Age Validation
class User { private _age: number = 0; get age(): number { return this._age; } set age(v: number) { if (v > 0 && v < 150) this._age = v; else console.error("Invalid age"); } } const u = new User(); u.age = 25; // ✅ u.age = -5; // Invalid age
Full Name Split
class Person { private _first: string = ''; private _last: string = ''; get fullName() { return `${this._first} ${this._last}`; } set fullName(name: string) { const parts = name.split(" "); if (parts.length === 2) [this._first, this._last] = parts; else console.error("Invalid format"); } } const p = new Person(); p.fullName = "John Doe"; console.log(p.fullName); // John Doe p.fullName = "John"; // Invalid format
