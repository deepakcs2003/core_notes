TypeScript Generics

Core Concept
🔷 Generics in TypeScript allow developers to create reusable and type-safe code that works with multiple data types (like string, number, boolean).

👉 Instead of writing separate code for each type, we write one flexible code using a placeholder type (T).
Basic Syntax
Syntax
function function_name<T>(
  parameter_name: T
): T {
  // code
}
  • function_name → function name
  • <T> → type parameter (placeholder for any type)
  • parameter_name: T → parameter depends on type
  • : T → return type also depends on same type
Generic Functions
✅ Example 1: Generic Function with Parameters
function displayData<T>(parameter: T): T {
  return parameter;
}

let result1 = displayData<string>("GeeksforGeeks");
let result2 = displayData<string>("Hello World !!");
let result3 = displayData<number>(1234567890);

console.log(result1);
console.log(result2);
console.log(result3);
Output
GeeksforGeeks Hello World !! 1234567890

Key Points

  • Function works for multiple types
  • Type is preserved (no data loss)
  • No need to rewrite logic
✅ Example 2: Generic Function with Array
let displayResult = <T>(data_item: T[]): T[] => {
  return new Array<T>().concat(data_item);
}

let numbersArray = displayResult<number>([50, 60, 80, 90]);
let stringArray  = displayResult<string>(["Hello World", "GeeksforGeeks"]);

console.log(numbersArray);
console.log(stringArray);

numbersArray.push(100);
stringArray.push("Apple");

console.log(numbersArray);
console.log(stringArray);
Output
[50, 60, 80, 90] ["Hello World", "GeeksforGeeks"] [50, 60, 80, 90, 100] ["Hello World", "GeeksforGeeks", "Apple"]

Key Points

  • Works with arrays of any type
  • Type safety maintained (number → number only, string → string only)
  • Return type matches input
✅ Example 3: Multiple Generic Parameters
let displayResult = <T, U>(id: T, name: U) => {
  return id + " - " + name;
}

let data1 = displayResult<number, string>(2000, "GeeksforGeeks");
let data2 = displayResult<number, string>(2001, "Hello World !!");

console.log(data1);
console.log(data2);
Output
2000 - GeeksforGeeks 2001 - Hello World !!

Key Points

  • Multiple types can be used (T, U)
  • Useful when working with different data together
✅ Example 4: Generic Constraints
function getLength<T extends { length: number }>(arg: T): number {
  return arg.length;
}

console.log(getLength("Hello"));
console.log(getLength([10, 20, 30]));
Output
5 3

Key Points

  • extends is used to restrict types
  • Only values with length property allowed
  • Prevents invalid inputs
Generic Functions (More Usage)
✅ Single Type Parameter
function gfg<T>(arg: T): T {
  return arg;
}

let result1: string  = gfg<string>("GEEKSFORGEEKS");
let result2: number  = gfg<number>(740);
let result3: boolean = gfg<boolean>(false);
  • Works for multiple types with same logic
✅ Generic Function with Array Parameter
function arrayEl<T>(arr: T[]): void {
  for (const x of arr) {
    console.log(x);
  }
}

let elements:  number[] = [101, 102, 103];
arrayEl(elements);

let elements1: string[] = ["Geeks", "For", "Geeks"];
arrayEl(elements1);
  • Works with different array types safely
✅ Multiple Types with Merge
function mergeArrays<T, U>(arr1: T[], arr2: U[]): (T | U)[] {
  return [...arr1, ...arr2];
}

const numbers: number[] = [1, 2, 3];
const words:   string[] = ["hello", "world"];

const mergedArray = mergeArrays(numbers, words);
console.log(mergedArray);
Output
[1, 2, 3, "hello", "world"]
  • Returns combined array with both types
Generic Constraints (Detailed)
Generic constraints restrict which types can be used.

Syntax: function func<T extends Type>(param: T) {}
✅ Example 1: Interface Constraint
interface Sports {
  name: string;
}

function printSportName<T extends Sports>(sport: T): void {
  console.log(sport.name);
}

let sport = { name: "baseball" };
printSportName(sport);
Output
baseball
  • Ensures object has name property
✅ Example 2: keyof Constraint
interface Sports {
  name:    string;
  players: number;
}

function getNumberOfPlayers<T extends Sports, K extends keyof T>(
  sport: T,
  key: K
): T[K] {
  return sport[key];
}

let sport   = { name: "baseball", players: 9 };
let players = getNumberOfPlayers(sport, 'players');

console.log(players);
Output
9
  • keyof ensures valid property access
✅ Example 3: Class with Constraint
interface Sports {
  name:    string;
  players: number;
  getNumberOfGloves(): number;
}

class Baseball implements Sports {
  constructor(public name: string, public players: number) {}

  getNumberOfGloves(): number {
    return this.players * 2;
  }
}

function getNumberOfGloves<T extends Sports>(sport: T): void {
  console.log(sport.getNumberOfGloves());
}

let baseball = new Baseball("baseball", 9);
getNumberOfGloves(baseball);
Output
18
  • Ensures class follows structure
Generic Object Types
Generic object types allow flexible object structures.
Syntax
type MyGenericObject<T> = {
  key:   string;
  value: T;
};
✅ Example 1: Key-Value Pair
type KeyValuePair<T> = {
  key:   string;
  value: T;
};

const stringPair: KeyValuePair<string> = { key: 'name', value: 'John' };
const numberPair: KeyValuePair<number> = { key: 'age',  value: 30 };

console.log(stringPair);
console.log(numberPair);
Output
{ key: 'name', value: 'John' } { key: 'age', value: 30 }
  • Same structure works with different value types
✅ Example 2: Data Container
type DataContainer<T> = {
  data: T;
};

const numericData: DataContainer<number> = { data: 25 };
const stringData:  DataContainer<string> = { data: 'TypeScript' };

console.log(numericData.data);
console.log(stringData.data);
Output
25 TypeScript
  • Encapsulates different data types
Generic Classes
Syntax
class GenericClass<T> {
  constructor(private value: T) {}

  getValue(): T {
    return this.value;
  }
}
✅ Example 1: Basic Generic Class
class Box<T> {
  private content: T;

  constructor(content: T) {
    this.content = content;
  }

  getContent(): T {
    return this.content;
  }
}

const numBox = new Box<number>(100);
const strBox = new Box<string>("Hello");

console.log(numBox.getContent());
console.log(strBox.getContent());
Output
100 Hello
  • Stores any type safely
✅ Example 2: Class with Constraint
class Box<T extends number> {
  constructor(private value: T) {}

  double(): number {
    return this.value * 2;
  }
}

const numBox = new Box(10);
console.log(numBox.double());
Output
20
  • Only numbers allowed
✅ Example 3: Multiple Types in Class
class Pair<K, V> {
  constructor(private key: K, private value: V) {}

  getKey():   K { return this.key;   }
  getValue(): V { return this.value; }
}

const userPair = new Pair<number, string>(1, "John");
  • Stores two different types
✅ Example 4: Static with Generics
class Counter<T> {
  static count = 0;

  constructor(private value: T) {
    Counter.count++;
  }

  static getCount() {
    return Counter.count;
  }
}

new Counter<number>(10);
new Counter<string>("Hello");

console.log(Counter.getCount());
Output
2
  • Static is shared across all instances

🔷 Final Conclusion

  • Generics = Reusable + Type-safe code
  • Use <T> as type placeholder
  • Works with: Functions, Arrays, Objects, Classes
  • Constraints (extends) ensure safety
  • Reduces errors and code duplication
