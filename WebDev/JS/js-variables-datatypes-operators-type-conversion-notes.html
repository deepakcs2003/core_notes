Variables and Datatypes
in JavaScript

JavaScript uses Variables → to store data and Data Types → to define what type of data is stored.

📄 GFG · Variables & Data Types 📄 GFG · Operators 📄 GFG · Type Conversion & Coercion
🧠
What is a Variable?
Basics

👉 A variable is like a container (box) that stores values.

Example:

let name = "Deepak";
📌 Here:
name → variable    "Deepak" → value
🔑
Ways to Declare Variables
3 Keywords

JavaScript has 3 keywords:

  1. var
  2. let
  3. const
🔴 1. var (Old Way)
var n = 5;
n = 20; // allowed
var n = 30; // allowed again
📌 Features:
  • Function-scoped (or global)
  • Can redeclare
  • Can update
⚠️ Problem:
  • Causes bugs due to re-declaration
  • Not recommended in modern JS
🟡 2. let (Modern Way)
let n = 10;
n = 20; // allowed
// let n = 15; ❌ error
📌 Features:
  • Block-scoped ({})
  • Cannot redeclare in same block
  • Can update value
✅ Best for: Changing values
🟢 3. const (Constant)
const n = 100;
// n = 200 ❌ error
📌 Features:
  • Block-scoped
  • Cannot reassign
  • Must initialize
⚠️ Important: 
const obj = {name: "Amit"};
obj.name = "Rahul"; // ✅ allowed
👉 Object content can change, but variable cannot be reassigned

Data Types in JavaScript
Two Types
  1. Primitive
  2. Non-Primitive
🔵
Primitive Data Types
Store single value · Immutable
👉 Store single value    👉 Immutable (cannot change directly)
1. Number
let n = 42;
let pi = 3.14;

👉 Includes: Integers, Decimals

2. String
let s = "Hello";

👉 Text inside: " " or ' '

3. Boolean
let isTrue = true;

👉 Only: true or false

4. Undefined
let x;
console.log(x); // undefined

👉 Variable declared but no value

5. Null
let empty = null;

👉 Intentional empty value

🔥 Difference:
nullundefined
intentionalaccidental
assigned manuallyautomatic
6. Symbol
let sym = Symbol("id");

👉 Unique value (used in objects)

7. BigInt
let big = 12345678901234567890n;

👉 For very large numbers

🟣
Non-Primitive Data Types
Store multiple / complex data
👉 Store multiple values / complex data
1. Object
let obj = {
    name: "Amit",
    age: 25
};

👉 Key-value pairs

2. Array
let arr = [1, 2, 3];

👉 Ordered list

3. Function
function greet() {
    console.log("Hello");
}

👉 Reusable block of code

Important Concepts (Tricky Expressions)
Step-by-Step Explanation
1. null === undefined
console.log(null === undefined); // false
📌 Why?
Different types · === checks type + value
2. 5 > 3 > 2
console.log(5 > 3 > 2); // false
1
5 > 3 → true
2
true → 1
3
1 > 2 → false
3. [] === []
console.log([] === []); // false
📌 Why?
Arrays are objects · Compared by reference, not value
4. "10" < "9"
console.log("10" < "9"); // true
📌 Why?
String comparison → character by character · "1" < "9" → true
5. NaN === NaN
console.log(NaN === NaN); // false
📌 Why?
Special rule in JS · NaN is NOT equal to itself
👉 Correct way: Number.isNaN(NaN); // true
6. true == 1
console.log(true == 1); // true
📌 Why?
== → type conversion · true → 1
⚠️ Tip: Always use === (strict equality)
7. undefined > 0
console.log(undefined > 0); // false
📌 Why?
undefined → NaN · NaN comparison → always false
8. "5" === 5
console.log("5" === 5); // false
📌 Why?
Different types (string vs number)
9. [1,2] == [1,2]
console.log([1,2] == [1,2]); // false
📌 Why?
Different memory reference
10. Infinity > 1000
console.log(Infinity > 1000); // true
📌 Why?
Infinity = unlimited large number

JavaScript Operators

JavaScript Operators

👉 Definition: JavaScript operators are symbols or keywords used to perform operations on Values and Variables 

let sum = 5 + 3;

Here: + → operator    5, 3 → operands

🧠 Why Operators are Important?
  • Used in calculations
  • Used in conditions (if, loops)
  • Used in data manipulation
  • Foundation of all logic in JS
🔢
1. Arithmetic Operators
Mathematical Calculations
const sum  = 5 + 3;   // 8
const diff = 10 - 2; // 8
const mul  = 4 * 2;   // 8
const div  = 8 / 2;   // 4
OperatorMeaning
+Addition
-Subtraction
*Multiplication
/Division
%Modulus (remainder)
**Power
⚠️ Important:
5 % 2 = 1
2 ** 3 = 8
📝
2. Assignment Operators
Assign Values to Variables
let n = 10;
n += 5; // 15
n *= 2; // 30
OperatorMeaning
=Assign
+=Add and assign
-=Subtract and assign
*=Multiply and assign
/=Divide and assign
⚖️
3. Comparison Operators
Compare values → return true/false
console.log(10 > 5);     // true
console.log(10 === "10"); // false
OperatorMeaning
>Greater
<Less
>=Greater equal
<=Less equal
==Loose equality
===Strict equality
!=Not equal
!==Strict not equal
⚠️ Important Difference: 
5 == "5"   // true (type conversion)
5 === "5"  // false (no conversion)
👉 Always prefer ===
🔗
4. Logical Operators
Used in Conditions
const a = true, b = false;

a && b // false
a || b // true
!a     // false
OperatorMeaning
&&AND
||OR
!NOT
🧠 Logic:
&& → both true
|| → at least one true
! → reverse
💻
5. Bitwise Operators
Work on binary (0/1)
5 & 1 // 1
OperatorMeaning
&AND
|OR
^XOR
~NOT
🧠 Example: 
5 → 101
1 → 001
& → 001 → 1
❓
6. Ternary Operator
Shortcut of if-else
const age = 18;
const status = age >= 18 ? "Adult" : "Minor";
📌 Syntax:
condition ? true_value : false_value
✅ Use: Short conditions · Clean code
🔄 7. Comma Operator

👉 Executes multiple expressions → returns last value

let n1, n2;
const res = (n1 = 1, n2 = 2, n1 + n2);
console.log(res); // 3
📌 Rule:
Left → right execution · Returns last result
🔼
8. Unary Operators
Work on single operand
let x = 5;

console.log(++x); // 6
console.log(x--); // 6 (then x becomes 5)
OperatorMeaning
++Increment
--Decrement
typeofGet type
🔥 Pre vs Post: 
++x → first increase, then use
x++ → first use, then increase
🔍 9. Relational Operators

👉 Check relationships

const obj = { length: 10 };

"length" in obj      // true
[] instanceof Array  // true
OperatorMeaning
inproperty exists
instanceofobject type check
🔢 10. BigInt Operators

👉 For very large numbers

const big1 = 12345678901234567890n;
const big2 = 10n;

console.log(big1 + big2);
⚠️ Rule:
10n + 5 ❌ error
👉 Cannot mix BigInt and Number
🔤 11. String Operators

👉 Used to join strings

const s = "Hello" + " World";
OperatorMeaning
+Concatenate
+=Append
🧠 Example:
"Hello" + 5 → "Hello5"
🔗
12. Optional Chaining Operator (?.)
Safe access to nested data
const obj = {
  name: "Aman",
  address: { city: "Delhi" }
};

console.log(obj.address?.city);   // Delhi
console.log(obj.contact?.phone); // undefined
📌 Why needed?
👉 Avoid errors like: obj.contact.phone ❌ error
✅ Advantage: No crash · Safe access
⚠️ Important Concepts (Must Know)

🔥 Operator Precedence

👉 Order of execution

5 + 2 * 3 = 11

👉 * runs first

🔄 Type Coercion

"5" + 2 = "52"
"5" - 2 = 3

⚠️ Short-Circuiting

true || false → true
Type System Complete Guide

Type Conversion & Type Coercion

JavaScript is dynamically typed, meaning: 👉 Variable type can change at runtime.
JavaScript provides 2 ways to change data types: Type Conversion (Explicit) and Type Coercion (Implicit)

🔄
1. Type Conversion (Explicit)
Manually converting one data type to another
📌 Also called: Explicit Type Casting
🔑 Key Features:
  • Done by programmer
  • Uses functions like: Number(), String(), Boolean()
  • Gives full control
🔢 Types of Type Conversion
1. String → Number
let s = "123";
let n = Number(s);
console.log(n); // 123
🧠 Other Methods: 
parseInt("123");   // 123
parseFloat("12.5"); // 12.5
⚠️ Important Cases: 
Number("123abc"); // NaN
parseInt("123abc"); // 123
👉 parseInt stops at invalid character
👉 Number fails completely
2. Number → String
let n = 123;
let s = String(n);
🧠 Shortcut: 
let s = n + "";
3. Boolean → Number
Number(true);  // 1
Number(false); // 0
4. Boolean → String
String(true); // "true"
📊 Summary of Type Conversion
FromToResult
"123" → NumberNumber123
true → NumberNumber1
false → NumberNumber0
123 → StringString"123"
⚡
2. Type Coercion (Implicit)
Automatic conversion done by JavaScript
📌 Also called: Implicit Type Casting
🔑 Key Features:
  • Done by JavaScript engine
  • Happens during: Operations (+, -), Comparisons (==)
  • Can cause unexpected results
1. String + Number
let n = 5;
let s = "5";

let res = n + s;
console.log(res);        // "55"
console.log(typeof res); // string
🧠 Why?
👉 If string is present → everything becomes string
2. Boolean + Number
true  + 10 // 11
false + 10 // 10
🧠 Rule:
true → 1    false → 0
3. Comparison (Different Types)
"10" == 10 // true
🧠 Why?
👉 "10" → converted to number
⚠️ Important:
"10" === 10 // false
👉 === does NOT convert types
4. Boolean Context (if condition)
let s = "";

if (s) {
   console.log("true");
} else {
   console.log("false");
}
👉 Output: false
🧠 Truthy & Falsy Values
❌ Falsy:
  • false
  • 0
  • "" (empty string)
  • null
  • undefined
  • NaN
✅ Truthy:

Everything else

⚠️ Important Coercion Rules

🔹 "+" Operator Special Case

"5" + 2 = "52"
"5" - 2 = 3

👉 + → string concatenation    👉 - → numeric conversion

🔹 Null & Undefined

null == undefined  // true
null === undefined // false

🔹 NaN Behavior

NaN == NaN // false

👉 Use: Number.isNaN(NaN) // true

👉 Type Conversion:

⚠️ Common Mistakes (VERY IMPORTANT)
❌ Using ==
0 == false // true
"" == 0    // true

👉 Confusing results

✅ Use ===
0 === false // false
❌ Mixing types
"5" + 1 // "51"
✅ Fix
Number("5") + 1 // 6
🧠
Best Practices
Must Follow
  • ✔ Always use explicit conversion
  • ✔ Prefer === over ==
  • ✔ Check type using: typeof value
  • ✔ Convert input before use: let num = Number(input);
