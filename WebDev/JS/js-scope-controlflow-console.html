Scope of Variables

Scope = where a variable can be used (accessed) in your code. It decides where a variable is visible, where you can use it, and how long it lives.

📄 GFG · Global Scope 📄 GFG · Block Scope
Basic Understanding Example

x → global variable (can use anywhere)  |  y → local variable (only inside function)

scope-intro.js
let x = 10;

function func() {
    let y = 20;
    console.log(x, y);
}

func();
📌 There are 5 main types of scope: Global, Local, Block, Lexical, and Module Scope.
🌐
1. Global Scope Accessible Everywhere
What is Global Scope? Global

A variable declared outside any function or block is global. It's accessible everywhere — inside functions ✔ and outside functions ✔.

✔ Accessible inside any function
✔ Accessible outside any function
✔ Lives for the entire program
✔ Declared at top-level
global-scope.js
const x = 10; // Global variable

function fun1() {
    console.log(x); // ✔ Can access x
}

fun1();
📌 Global = "sab jagah available" — available everywhere in code.
🏠
2. Local Scope Inside Function Only
What is Local Scope? Local

A variable declared inside a function is local. It's only accessible inside that function — cannot be used outside ❌.

local-scope.js
function fun2() {
    let x = 10; // Local variable
    console.log(x); // ✔ Works fine
}

fun2();
// console.log(x); ❌ Error — x is not defined
📌 Local = "sirf ghar ke andar allowed" — only accessible inside the function.
⚠️ Important: Before ES6 History

Before ES6 (2015), only var was used. It had serious problems.

❌ Before ES6 — var

  • Function scoped only
  • Global pollution 😵
  • Hoisting issues
  • Block scope ignored

✅ After ES6 — let / const

  • Block scoped
  • No pollution
  • Safer hoisting
  • Better control
🧱
3. Block Scope Inside { } Only
What is Block Scope? Block

Block = { } (like if-blocks, loops). let and const are block-scoped. var is NOT block-scoped.

block-scope.js
{
    var x = 10;
    const y = 20;
    let z = 30;

    console.log(x); // ✔ OK
    console.log(y); // ✔ OK
    console.log(z); // ✔ OK
}

console.log(x);   // ✔ OK — var escapes block
// console.log(y); ❌ Error — const is block-scoped
// console.log(z); ❌ Error — let is block-scoped
VariableBlock Scoped?Accessible Outside?
var❌ No✔ Yes — escapes block
let✔ Yes❌ Only inside block
const✔ Yes❌ Only inside block
📌 var ignores block boundaries. let & const strictly follow block scope.
🔗
4. Lexical Scope Very Important
What is Lexical Scope? Lexical

Lexical = where code is written. An inner function can access its own variables and the parent function's variables. But the outer function cannot access inner variables.

lexical-scope.js
function func1() {
    const x = 10;

    function func2() {
        const y = 20;
        console.log(x, y); // ✔ func2 can access x from parent
    }

    func2();
}

func1();
✔ Inner function → can access outer variables
✗ Outer function → cannot access inner variables
📦
5. Module Scope File Level
What is Module Scope? Module

Used in multiple files (modules). Variables inside one file are private. Use export to share them and import to use them in another file.

📁 math.js
export const number = 10;

export function add(a, b) {
    return a + b;
}
📁 main.js
import { number, add } from "./math.js";

console.log(number);        // 10
console.log(add(5, 3));    // 8
📌 Module scope prevents global conflicts and keeps code organized.

Control Flow Statements

Control Flow = the order in which code runs. By default it runs top → bottom. Control flow statements let us make decisions, repeat code, and jump around the execution.

📄 GFG · Loops 📄 GFG · Switch
📌 Control flow statements control execution order, allow decisions, loops, and jumps in code.
🔹
if Statement Basic Decision
What is the if Statement? Conditional

Used when you want to take decisions. If the condition is true → code executes. If false → skipped.

if-statement.js
let age = 18;

if (age >= 18) {
   console.log("You are adult");
}
🔹
if...else Statement Two Paths
if...else Statement Conditional

Always one block runs. If condition is true → if block. If false → else block.

if-else.js
let age = 16;

if (age >= 18) {
   console.log("Adult");
} else {
   console.log("Not Adult");
}
🔹
else if Ladder Multiple Conditions
else if Ladder Conditional

Multiple conditions checked in sequence. The first true condition executes, rest are skipped.

else-if.js
let num = 0;

if (num > 0) {
   console.log("Positive");
} else if (num < 0) {
   console.log("Negative");
} else {
   console.log("Zero");
}
🔹
switch Statement Multiple Values
switch Statement Conditional

Compares one variable against multiple values. break is important — without it, execution "falls through" to the next case.

switch.js
let day = 2;

switch(day) {
   case 1:
      console.log("Monday");
      break;
   case 2:
      console.log("Tuesday");
      break;
   default:
      console.log("Other day");
}
📌 switch replaces long if-else chains when comparing one variable to many values.
🔹
Ternary Operator ?: One-line Decision
Ternary Operator Short Form

Short form of if-else. Syntax: condition ? trueValue : falseValue

ternary.js
let age = 20;

let result = (age >= 18) ? "Adult" : "Not Adult";
console.log(result); // "Adult"
Nested if Complex Logic

One if inside another if. Used for complex conditions.

nested-if.js
let marks = 85;

if (marks >= 50) {
   if (marks >= 80) {
      console.log("Excellent");
   }
}
🔁
Looping Statements Repetition
for Loop Loop

Used when you know exactly how many times to repeat. Has 3 parts: init, condition, increment.

for-loop.js
for (let i = 0; i < 5; i++) {
   console.log(i);
}
// Output: 0 1 2 3 4
while Loop Loop

Runs as long as the condition is true. Condition is checked before each iteration.

while-loop.js
let i = 0;

while (i < 5) {
   console.log(i);
   i++;
}
do...while Loop Loop

Runs at least once regardless of condition. Condition is checked after each iteration.

do-while.js
let i = 0;

do {
   console.log(i);
   i++;
} while(i < 5);
📌 Key difference: do…while always executes at least 1 time even if the condition is false from the start.
⛔
Jump / Branch Statements Control Loop Flow
break Jump

Immediately stops the loop and exits.

break.js
for (let i = 0; i < 5; i++) {
   if (i === 3) break;
   console.log(i);
}
// Output: 0 1 2
continue Jump

Skips the current iteration and moves to the next one.

continue.js
for (let i = 0; i < 5; i++) {
   if (i === 3) continue;
   console.log(i);
}
// Output: 0 1 2 4

Console Object

The console object is used to print messages, debug code, check errors, and test code while running. It works in the Browser console (Chrome DevTools) and Node.js terminal.

📄 console.log() 📄 console.trace()
1️⃣
console.log() Most Used
console.log() Output

Used to print normal messages. Most commonly used method for debugging and checking values.

console-log.js
console.log("Hello, World!");
// Output: Hello, World!
2️⃣
console.error() Error Messages
console.error() Error 🔴

Used to print error messages. Usually shown in red color 🔴. Helps identify problems quickly.

console-error.js
console.error("This is an error message.");
// Output: This is an error message. (in red)
3️⃣
console.warn() Warning Messages
console.warn() Warning ⚠️

Used to show warning messages. Shown in yellow ⚠️. Indicates something might go wrong.

console-warn.js
console.warn("This is a warning message.");
// Output: ⚠ This is a warning message. (in yellow)
console.info() Info

Used for informational messages. Similar to console.log(). Can be styled using %c.

console-info.js
console.info('%cStyled info message!',
             'color: blue; font-size: 16px; font-weight: bold;');
5️⃣
console.table() Tabular Data
console.table() Table

Displays data in table format. Works with arrays and objects. Easy to read large data.

console-table.js
console.table([
  {name: "Amit", age: 30},
  {name: "Jatin", age: 25}
]);
// (index)  name     age
// 0        Amit     30
// 1        Jatin    25
6️⃣
console.time() & timeEnd() Performance
console.time() & console.timeEnd() Timer

Used to measure execution time. Start with time(), end with timeEnd(). Useful for performance testing.

console-time.js
console.time('timer1');

function loops() {
    for (let i = 0; i <= 10000; i++) {}
}

loops();

console.timeEnd('timer1');
// Output: timer1: 0.359ms
7️⃣
console.assert() Condition Check
console.assert() Assert

Checks a condition. If condition is false → error shown. If true → nothing happens. Used for testing conditions.

console-assert.js
console.assert(5 > 10, "This assertion failed");
// Output: Assertion failed: This assertion failed
8️⃣
console.group() & groupEnd() Organized Logs
console.group() & console.groupEnd() Group

Used to group logs together. Makes logs organized. Helpful in big programs.

console-group.js
console.group('User Information');
console.log('Name: Ritik');
console.log('Age: 30');
console.groupEnd();
// User Information
//   Name: Ritik
//   Age: 30
9️⃣
console.count() Execution Counter
console.count() Count

Counts how many times it runs. Tracks execution count. Useful for loops and functions.

console-count.js
console.count("countLabel");  // countLabel: 1
console.count("countLabel");  // countLabel: 2
console.count("countLabel");  // countLabel: 3
🔟
console.trace() Call Stack
console.trace() Trace

Shows call stack (execution path). Shows function calling order. Very useful for tracking bugs in complex code.

console-trace.js
function a() { b(); }
function b() { c(); }
function c() { console.trace(); }

a();
// Output: c → b → a (call stack)
