Introduction to JavaScript

JavaScript is a programming language used mainly to make websites interactive and dynamic. It works alongside HTML (structure) and CSS (design) to add logic and behavior to webpages.

📄 GFG · Introduction 📄 GFG · Where to Put JS
📘

Introduction to JavaScriptWhat and Why

❌ Without JavaScript

Webpage is static — only text and images, no interactivity.

✅ With JavaScript

  • Buttons work
  • Forms validate
  • Animations run
  • Content changes dynamically
💡

Key Idea: HTML = Structure  |  CSS = Design  |  JavaScript = Logic

⚙️

Core CharacteristicsHow JS works

1. Single-Threaded Default

JavaScript executes one task at a time. It does NOT run multiple tasks simultaneously in parallel by default.

example.js
console.log("Task 1");
console.log("Task 2");
✔

Output: Task 1 → Task 2 (in order, one by one)

2. Interpreted Language

  • Code runs line by line
  • No need to compile before running
  • Means faster development and easy debugging

3. Dynamically Typed

Variable type is decided at runtime, not compile time.

types.js
let x = 10;      // number
x = "hello";   // now string — no error!
📌

No need to declare types like C++ or Java.

Features of JavaScriptWhy JS is powerful

1. Client-Side Scripting

  • Runs in browser
  • Fast response — no server call needed
  • Example: Form validation before submit

2. Versatile

  • Web development
  • Mobile apps
  • Backend (Node.js)
  • Games

3. Event-Driven

Responds to user actions:

event.js
button.onclick = function() {
   alert("Clicked!");
}

4. Asynchronous

  • Can do multiple things without blocking UI
  • Example: Fetch data while page is still usable

5. Rich Ecosystem

Popular libraries and frameworks:

React Angular Vue
📌

These frameworks make development faster and more organized.

Programming ParadigmsWays to write code

1. Imperative Programming

👉

Focus: How to do — Step-by-step instructions

imperative.js
let sum = 0;
for(let i=0; i<5; i++){
   sum += i;
}

2. Declarative Programming

👉

Focus: What to do — Cleaner and shorter

declarative.js
let arr = [1,2,3,4];
let sum = arr.reduce(
  (a,b) => a+b
);

Limitations of JavaScriptThings to watch out for

1. Security Risks

⚠

XSS (Cross-Site Scripting) — Hacker injects malicious script into webpage

2. Performance Issues

  • Slower than languages like C++
  • But fine for normal web tasks

3. Complexity

Advanced JS requires understanding of:

Closures Async Handling Objects

4. Weak Type Checking

No strict type enforcement — can cause bugs:

types.js
"5" + 2 = "52"  // not 7!

Ways to Add JavaScript in HTML3 methods

🔴 Inline

Written directly inside HTML tags. Good for small tasks, quick testing.

🟡 Internal

Written inside <script> tag in the same HTML file.

🟢 External

Written in a separate .js file. Best for large projects.

🔴

1. Inline JavaScriptDirectly in HTML tag

inline.html
<button onclick="alert('Button Clicked!')">
    Click Here
</button>
  • onclick — event triggered when button is clicked
  • alert() — shows popup message
✅

Use when: Small tasks, quick testing

❌

Problems: Messy code, hard to maintain, not reusable

🟡

2. Internal JavaScriptInside <script> tag

A. Inside <head> Tag

head.html
<head>
    <script>
        function myFun() {
            document.getElementById("demo")
              .innerHTML = "Content changed!";
        }
    </script>
</head>
⚠️

Runs before page loads fully. If element not loaded → error possible.

B. Inside <body> Tag Safer

body.html
<body>
    <h3 id="demo">GeeksforGeeks</h3>

    <button onclick="myFun()">Click</button>

    <script>
        function myFun() {
            document.getElementById("demo")
              .innerHTML = "Content changed!";
        }
    </script>
</body>
✅

Script runs after HTML loads. Safer when working with DOM.

✅

Use when: Medium size projects, simple pages

❌

Problems: Code mixed with HTML, not reusable across files

🟢

3. External JavaScript Best MethodSeparate .js file

📄 HTML File

index.html
<script src="script.js"></script>

📄 script.js

script.js
function myFun() {
    document.getElementById("demo")
      .innerHTML = "Content changed!";
}

✅ Advantages of External JavaScript

⚡

Faster Loading — Browser caches .js file, no reload every time

🧹

Clean Code — HTML = structure, JS = logic, separated cleanly

🔧

Easy Maintenance — Update one file → changes everywhere

♻️

Reusability — Same JS file used in multiple pages

⚡

async vs deferScript loading behavior

⚠️

By default, JavaScript blocks page loading. Use async or defer to fix this.

🔵 async

html
<script src="script.js"
        async></script>
  • Loads in background
  • Executes immediately when ready
  • Does NOT wait for HTML
⚠

Order is NOT guaranteed

🟢 defer

html
<script src="script.js"
        defer></script>
  • Loads in background
  • Executes AFTER HTML loads
  • Best for DOM manipulation
  • Safe execution guaranteed
✅

Recommended for most use cases

📂
