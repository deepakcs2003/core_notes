Section 1 — What is React?

React kya hai?

React ek JavaScript library hai jo user interfaces (UI) build karne ke liye use hoti hai.

Simple language mein: Jab tum kisi website par jaate ho, toh tumhe different elements dikhte hain:

  • Navbar
  • Sidebar
  • Buttons
  • Forms
  • Cards
  • Tables
  • Dashboard
  • Popup / Modal

In sabhi UI elements ko efficiently create aur manage karne ke liye React use karte hain.

Example: Tumhare IT Helpdesk project mein:

React mein hum UI ko chhote-chhote reusable components mein divide karte hain.

React ki important features

  1. Component Based Architecture: UI ko reusable components mein divide karna.
  2. Declarative UI: Tum batate ho ki UI kaisa dikhna chahiye, React rendering manage karta hai.
  3. Reusable Components: Ek component ko multiple places par use kar sakte ho.
  4. State Management: UI ka changing data manage kar sakte ho.
  5. One-way Data Flow: Parent component se child component ko props ke through data pass hota hai.
  6. Efficient Rendering: React changes ke according UI update karta hai.

React library hai ya framework?

React officially ek library hai, complete framework nahi.

React primarily UI layer handle karta hai. Routing, data fetching aur other application architecture ke liye additional libraries ya frameworks use kiye ja sakte hain.

Section 3 — useEffect with Dependencies

Dependency array decide karta hai ki Effect kab dobara execute hoga.

Is section ke 3 important patterns hain.

Pattern 1: No dependency array

  • Initial mount ke baad run hota hai.
  • Har subsequent committed render ke baad bhi run hota hai.

Pattern 2: Empty dependency array

  • Initial mount par run hota hai.
  • Normal production lifecycle mein har update par repeat nahi hota.

Pattern 3: Dependency array with value

  • Initial mount par run hota hai.
  • Jab count change hota hai, Effect dobara run hota hai.
  • Unrelated state change hone par nahi, jab tak listed dependencies same rahen.

Visual comparison

PatternKab run hota haiFlow
No dependency arrayEvery committed renderMount → Update → Update → Update
Empty array []Mount only in normal production lifecycleMount → No repeat on ordinary updates
[count]Mount + dependency changesMount → count changes → Effect runs

Multiple dependencies

Agar userId ya page change hota hai, Effect dobara synchronize hota hai.

Important rule

Effect ke andar jo reactive values use ki hain, unhe dependencies mein include karna chahiye. React ESLint rules ismein help karte hain.

Section 9 — Keeping Components Pure

React documentation ka important principle hai: components ko pure functions ki tarah likhna.

Pure function kya hai?

Ek pure function:

  1. Same input par same output return karta hai.
  2. Existing external variables ya objects ko modify nahi karta.
  3. Hidden side effects perform nahi karta.

Example:

Same inputs → same output.

Impure function

Ye external variable modify kar raha hai.

Isliye pure nahi hai.

React component mein purity

Correct:

Same name prop → same JSX.

Incorrect:

Component render hone par external variable modify ho raha hai.

Side Effects kya hain?

Examples:

  • API requests.
  • localStorage operations.
  • DOM manipulation.
  • Timer.
  • Event listeners.

Aise operations render phase ke andar directly nahi karne chahiye. Unhe appropriate event handler ya Effect mein handle karna chahiye.

React StrictMode

Development mein StrictMode extra renders aur Effect setup-cleanup cycles ke through bugs identify karne mein help karta hai.
