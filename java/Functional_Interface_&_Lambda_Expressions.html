1. What is a Functional Interface?

Definition: An interface with exactly ONE abstract method. 
@FunctionalInterface
interface Calculator {
    int calculate(int a, int b);  // Only one method → Functional Interface
}

Rules

Rule Explanation
Only 1 abstract method If 2+ → Not functional
Can have default methods OK
Can have static methods OK
Can have Object class methods toString(), equals() → Not counted
@FunctionalInterface Optional, but recommended (helps compiler check)

✅ Valid Functional Interface

Example: Valid

@FunctionalInterface
interface Printer {
    void print(String msg);  // 1 abstract method

    // Default method → OK
    default void printTwice(String msg) {
        print(msg);
        print(msg);
    }

    // Static method → OK
    static void info() {
        System.out.println("Printer Interface");
    }
}

❌ Invalid Example (Compilation Error)

Example: Invalid

@FunctionalInterface
interface Bad {
    void m1();
    void m2();  // Error! More than 1 abstract method
}

2. What is a Lambda Expression?

Definition: Short way to write a method without a name.

Instead of writing a full class, just write what it does.

⚠️ Old Way (Before Java 8) – Too Long!

Printer p = new Printer() {
    public void print(String msg) {
        System.out.println(msg);
    }
};
p.print("Hello");  // Hello

✨ Lambda Way (Java 8+) – Short & Clean!

Printer p = msg -> System.out.println(msg);
p.print("Hello");  // Hello

3. Lambda Syntax

Input Output Lambda Syntax Example
No input No return () -> action () -> System.out.println("Hi")
1 input No return x -> action name -> System.out.println(name)
1 input Return x -> value x -> x * x
2 inputs Return (a,b) -> value (a,b) -> a + b
Multiple lines Use { } (a,b) -> { ... } See below

Lambda Examples

// 1. No input
Runnable r1 = () -> System.out.println("Run!");

// 2. One input
Printer p = msg -> System.out.println(">> " + msg);

// 3. Two inputs
interface Add {
    int sum(int x, int y);
}
Add add = (x, y) -> x + y;

// 4. Multiple lines
Add mul = (x, y) -> {
    System.out.println("Multiplying...");
    return x * y;
};

4. How to Use Lambda? (Step by Step)

Step 1: Create Functional Interface

@FunctionalInterface
interface MathOp {
    int operation(int a, int b);
}

Step 2: Use Lambda

public class Main {
    public static void main(String[] args) {

        // Addition
        MathOp add = (a, b) -> a + b;
        System.out.println(add.operation(5, 3));  // 8

        // Subtraction
        MathOp sub = (a, b) -> a - b;
        System.out.println(sub.operation(5, 3));  // 2

        // Multiply with multiple lines
        MathOp mul = (a, b) -> {
            System.out.println("Calculating...");
            return a * b;
        };
        System.out.println(mul.operation(4, 5));  // Calculating... 20
    }
}

5. Built-in Functional Interfaces (Most Used)

Interface Method Use Case Lambda Example
Runnable run() Threads () -> System.out.println("Thread")
Consumer<T> accept(T) Do something s -> System.out.println(s)
Supplier<T> get() Return value () -> "Hello"
Function<T,R> apply(T) → R Transform x -> x * 2
Predicate<T> test(T) → boolean Filter n -> n > 10

Example: Using Built-in Interfaces

import java.util.function.*;

public class BuiltInExample {
    public static void main(String[] args) {

        // Consumer
        Consumer<String> print = s -> System.out.println(s);
        print.accept("Java");  // Java

        // Supplier
        Supplier<String> hello = () -> "Hello World";
        System.out.println(hello.get());  // Hello World

        // Function
        Function<Integer, Integer> square = x -> x * x;
        System.out.println(square.apply(5));  // 25

        // Predicate
        Predicate<Integer> isEven = n -> n % 2 == 0;
        System.out.println(isEven.test(4));  // true
    }
}

6. Lambda with Collections & Streams (Most Important!)

import java.util.*;
import java.util.stream.*;

public class StreamExample {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5, 6);

        // Filter even numbers
        List<Integer> evens = nums.stream()
                                  .filter(n -> n % 2 == 0)
                                  .toList();
        System.out.println(evens);  // [2, 4, 6]

        // Double each number
        List<Integer> doubled = nums.stream()
                                    .map(n -> n * 2)
                                    .toList();
        System.out.println(doubled);  // [2, 4, 6, 8, 10, 12]

        // Print each
        nums.forEach(n -> System.out.print(n + " "));
        // 1 2 3 4 5 6
    }
}

7. Method Reference (::) – Shorter than Lambda

Lambda Method Reference
x -> System.out.println(x) System.out::println
s -> s.toUpperCase() String::toUpperCase
(a,b) -> Math.max(a,b) Math::max

Example:

List<String> names = Arrays.asList("alice", "bob");

// Lambda
names.forEach(name -> System.out.println(name.toUpperCase()));

// Method Reference (Better)
names.forEach(System.out::println);  // Just print
names.forEach(String::toUpperCase);  // Print uppercase

8. Variable Capture in Lambda (Important Rule)

Lambda can use variables from outside, but:

Local variables must be final or effectively final (not changed after init)

✅ Correct

int value = 10;
Runnable r = () -> System.out.println(value);  // OK
r.run();

❌ Error (Cannot reassign)

int count = 0;
Runnable r = () -> System.out.println(count);
count = 5;  // Error! Cannot modify

✅ Instance variables → OK to modify

class Counter {
    int count = 0;
    Runnable r = () -> count++;  // OK
}

9. Full Working Code (Copy-Paste & Run)

// 1. Functional Interface
@FunctionalInterface
interface Operation {
    int apply(int a, int b);
}

// 2. Main Class
public class LambdaNotes {
    public static void main(String[] args) {

        // Lambda for addition
        Operation add = (x, y) -> x + y;
        System.out.println("5 + 3 = " + add.apply(5, 3));

        // Lambda for multiplication
        Operation mul = (x, y) -> {
            System.out.println("Multiplying...");
            return x * y;
        };
        System.out.println("4 * 6 = " + mul.apply(4, 6));

        // Using Predicate
        java.util.function.Predicate<Integer> isPositive = n -> n > 0;
        System.out.println("10 is positive? " + isPositive.test(10));

        // Stream + Lambda
        java.util.List<String> cities = java.util.Arrays.asList("Delhi", "Mumbai", "Pune");
        cities.stream()
              .filter(city -> city.startsWith("D"))
              .forEach(System.out::println);  // Delhi
    }
}
